# 🦕 Dino Español 🇪🇸

Ein kleines, kostenloses Browser-Lernspiel, das Match-3-Rätsel mit den ersten spanischen Vokabeln kombiniert. Funktioniert direkt im Browser – auf dem Desktop und auf dem Handy, ganz ohne Installation oder externe Bibliotheken.

## 🎮 Spielprinzip

1. **Eier tauschen:** Tippe zwei benachbarte Dino-Eier an, um sie zu tauschen.
2. **Dreierreihen bilden:** Bringe **3 Eier der gleichen Farbe** waagerecht oder senkrecht in eine Reihe.
3. **Vokabeln freischalten:** Nach **3 Kombinationen** schließt du das Level ab und schaltest 3 neue spanische Wörter frei.
4. **Aussprache anhören:** Mit einem Klick auf 🔊 liest der Browser die spanischen Wörter laut vor (Web Speech API, `es-ES`).
